# Guard Companion cross-role mobile and Android pilot checklist

Record the device model, Android version, browser version, site, user role, operator, date and result for every item. Run the relevant section with a representative guard, supervisor and owner.

## Shared checks

- Sign in, refresh, navigate, and sign out. Confirm the next user on a shared phone cannot see the previous user's data.
- Check the 360–390px layout and larger Android text. No essential control may be clipped, overlap or require horizontal scrolling.
- Record weak or interrupted connectivity behavior. The interface must state uncertainty honestly and must not claim delivery or synchronization that cannot be verified.

## Guard checks

- Sign in and sign out on a shared phone with two separate guard accounts.
- Deny and allow camera, microphone and location permissions; confirm the typed/manual fallbacks remain usable.
- Start/end a shift, complete a QR patrol, and try NFC only on a browser/device that supports it.
- Capture voice and photos offline, reload, reconnect, interrupt one upload, retry, and verify one server record with the expected media.
- Lock the screen during recording/upload; test low storage and weak/interrupted connectivity.

## Supervisor checks

- Open Today’s overview, Problems, Reports and Settings; select a shift/date, review a problem and return without header movement or clipped controls.
- Create or edit a shift, checkpoint and user using touch controls. If recorded shift instructions are enabled, deny microphone permission and confirm typed instructions remain usable.
- Confirm problem/media views, location-review states and stale-record wording are legible and do not imply that missing activity is an all-clear.

## Owner checks

- Open Property, Supervisors and Subscription; confirm the mobile layout keeps the owner’s multiple-property context clear.
- Test property location with location permission denied and confirm manual address/coordinate entry remains usable.
- If owner-as-supervisor is enabled, enter and leave that view and confirm identity, permissions and navigation remain clear.

Attach signed results to G6 in the remediation plan. Do not advertise NFC, background synchronization, delivery guarantees or any hardware capability until the relevant exercise passes on supported devices. Passing this checklist supplies field evidence; it does not by itself claim production readiness.
